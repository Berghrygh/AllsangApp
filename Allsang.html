🐙 GitHub-synk

Lagre databasen automatisk i ditt eget GitHub-repo, så er den i synk på alle enhetene dine. Brukernavn og repo blir oppdaget automatisk fra URL-en hvis appen kjører på GitHub Pages – du må kun fylle inn tokenet på hver enhet.

Slik oppretter du en token (én gang per enhet):
  1. Gå til github.com/settings/personal-access-tokens
  2. «Generate new token» → velg Fine-grained personal access token
  3. Repository access: Only select repositories → velg ditt allsang-repo
  4. Permissions → Repository permissions → Contents: Read and write
  5. Klikk «Generate token», kopier det og lim inn over

⚠️ Hver enhet trenger sin egen token – av sikkerhetshensyn lagres tokenet kun lokalt i hver nettleser.

Slik bruker du Allsang-appen

1. Legge til sanger

Trykk ＋ Ny sang, fyll inn artist og tittel. Bruk søkeknappene til å åpne søk etter tekst og besifring i nytt vindu. Kopier teksten du finner og lim inn.

2. Lage en set-list

Gå til Set-lister, opprett en ny, gi den et navn og legg til sanger. Bruk pilene til å endre rekkefølge.

3. Lage PDF

Trykk 📄 Lag PDF i en set-list. PDF får forside, innholdsfortegnelse, sidetall og én sang per side.

4. GitHub-synk på flere enheter

På hver ny enhet: åpne appen, gå til Data → fyll inn tokenet (brukernavn/repo oppdages automatisk), hak av Auto-synk, trykk Lagre til GitHub første gang. Etterpå synkroniseres alt automatisk på den enheten.

Ny sang

Klikk en knapp for å åpne søk i ny fane. Marker tekst+besifring, kopier og lim inn nedenfor.
